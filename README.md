# Kash Truck Sim (Stage 1)

Offline-ready truck driving game. No installs, no dependencies.

## Put it on GitHub and play on your phone
1. Create a new GitHub repository and upload every file in this folder.
2. Repository Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Open the link GitHub gives you (https://YOURNAME.github.io/REPO/) on your phone.
4. Browser menu > "Add to Home Screen" / "Install app". It then works offline.

## Make an APK
Paste your GitHub Pages link into pwabuilder.com and choose Android.

## Controls
Phone: arrow buttons steer, Gas / Brake pedals. Keyboard: arrows or WASD, Space brakes.
Mirror arrows adjust the mirrors. "Med" button changes graphics quality, "Clear" changes weather.
